# Glitch Rune Forge

Type any sentence and see it in Glitch Runes. Save it as a PNG or JPG in four sizes, or turn on
Glitch Rain and save a looping GIF, with a choice of rune sizes for the rain.

Everything runs in your browser. There is no server, no account, no cookies, no tracking, and
nothing you type is uploaded. Your last settings are remembered in your own browser only.

## Use it

Open the site's address in a current browser (Chrome, Edge, Firefox or Safari), on a computer or
a phone. On an iPhone, saved images open in their own tab: long-press the image, then Save to Photos.

## Host it anywhere

This folder is plain static files with relative paths and no build step.

1. Copy the whole folder to your web host (any folder name works).
2. Open the page's address in a browser.

It works on GitHub Pages or any shared host.

## Files

- `index.html` the page and its security policy
- `app.js` the app: rune setting, saving, Glitch Rain and the GIF writer
- `app.css` the look
- `fonts/` Glitch Runes, Barlow Condensed and Share Tech Mono, all SIL Open Font License 1.1 (see `fonts/OFL.txt`)
